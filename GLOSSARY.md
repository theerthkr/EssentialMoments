# Domain Glossary

- **Embedding**: An L2-normalized `FloatArray` in a shared multimodal vector space representing either a photo or a text query. Because all embeddings are L2-normalized at creation time, cosine similarity between any two embeddings reduces to their dot product.
- **ImageEmbedder**: The backend-agnostic image embedding interface (`ml/ImageEmbedder.kt`) that transforms a photo (`Uri`, URI string, or `Bitmap`) into an L2-normalized **Embedding**, encapsulating preprocessing, model inference, and normalization.
- **TextEmbedder**: The backend-agnostic text embedding interface (`ml/TextEmbedder.kt`) that transforms a search query string into an L2-normalized **Embedding**, encapsulating tokenization, model inference, and normalization.
- **EmbeddingModelFactory**: The single factory (`ml/EmbeddingModelFactory.kt`) providing active `ImageEmbedder` and `TextEmbedder` instances (`Backend.ONNX_INT8` by default, with `Backend.LITERT` retained) so callers remain decoupled from specific ML runtimes.
- **SiglipImagePreprocessor**: Shared SigLIP 2 preprocessing module (`ml/SiglipImagePreprocessor.kt`) that scales bitmaps to `224×224`, recycles temporary bitmaps, converts packed ARGB pixels into a normalized **NCHW Tensor**, and widens 32-bit BPE token IDs into `int64` (`LongArray`) for ONNX Runtime.
- **OnnxSiglipImageEmbedder**: The active ONNX Runtime INT8 SigLIP 2 image embedding adapter (`ml/onnx/OnnxSiglipImageEmbedder.kt`). Uses `SiglipImagePreprocessor` for NCHW preprocessing, stages `vision_model_int8.onnx` to a file path for off-heap `OrtSession` execution, requests `pooler_output` (`[1, 768]`), and L2-normalizes the output.
- **OnnxSiglipTextEmbedder**: The active ONNX Runtime INT8 SigLIP 2 text embedding adapter (`ml/onnx/OnnxSiglipTextEmbedder.kt`). Uses `SigLIPTokenizer` and `SiglipImagePreprocessor.tokenIdsToInt64` to construct `input_ids: int64[1, 64]`, stages `text_model_int8.onnx` for off-heap `OrtSession` execution, requests `pooler_output` (`[1, 768]`), and L2-normalizes the output.
- **LiteRtSiglipImageEmbedder**: The retained LiteRT SigLIP 2 image embedding adapter (`ml/litert/LiteRtSiglipImageEmbedder.kt`). Delegates preprocessing to `SiglipImagePreprocessor`, compiles `siglip2_base_patch16-224.tflite` with hardware accelerator fallback (`NPU -> GPU -> CPU`), reuses pre-allocated tensor buffers, and L2-normalizes the output.
- **LiteRtSiglipTextEmbedder**: The retained LiteRT SigLIP 2 text embedding adapter (`ml/litert/LiteRtSiglipTextEmbedder.kt`). Owns Gemma 256k BPE tokenization (`64` tokens with `<eos>` and `<pad>`), LiteRT model compilation with hardware accelerator fallback (`NPU -> GPU -> CPU`), tensor buffer reuse, and L2 normalization.
- **NCHW Tensor**: Channel-first contiguous `FloatArray` of size `1 × 3 × 224 × 224` (`150,528` floats: all Red values, then all Green values, then all Blue values, rescaled from `[0, 255]` to `[-1.0, 1.0]`) required by the SigLIP 2 vision model.
- **MediaCatalog**: Deep media access interface (`media/MediaCatalog.kt`) hiding MediaStore cursors, column parsing, and URI normalization behind a single seam. Normalizes all photo URIs to canonical `content://media/external/images/media/<id>`.
- **AndroidMediaCatalog**: Production adapter for `MediaCatalog` (`media/AndroidMediaCatalog.kt`) backed by Android `ContentResolver`.
- **VectorIndex**: Deep vector storage interface (`data/VectorIndex.kt`) encapsulating deduplication set filtering, batch persistence, and nearest-neighbor similarity search.
- **ObjectBoxVectorIndex**: Production adapter for `VectorIndex` (`data/ObjectBoxVectorIndex.kt`) using ObjectBox `@HnswIndex(dimensions = 768, distanceType = VectorDistanceType.COSINE)` for off-heap native C++ nearest-neighbor ranking with near-zero Kotlin heap consumption. Also provides `queryAll` for exact dot-product scans.
- **InMemoryVectorIndex**: Fast in-memory JVM adapter for `VectorIndex` (`data/InMemoryVectorIndex.kt`) enabling deterministic unit testing without native database binaries.
- **PhotoIndexer**: Deep photo indexing module (`indexing/PhotoIndexer.kt`) serving as the single source of truth for photo indexing progress and pipeline orchestration (`allPhotoUris` -> batch deduplication -> `ImageEmbedder` batch -> `VectorIndex.putBatch`).
- **IndexingScheduler**: Single scheduling module (`indexing/IndexingScheduler.kt`) that encapsulates Android WorkManager unique-work queuing and parameters.
- **InferenceArbiter**: Concurrency and priority coordinator (`ml/InferenceArbiter.kt`) allowing high-priority interactive search queries (`TextEmbedder`) to cooperatively preempt background photo indexing (`ImageEmbedder`) in-process between frames without abruptly killing or restarting WorkManager jobs.
