# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Essential Moments is an offline-first, on-device application designed to respect user privacy by processing all neural embeddings locally.

If you discover a security vulnerability or sensitive data leak risk, please do not disclose it publicly in an open GitHub issue. Instead, please report it privately:

- Contact the maintainer via email: `theerth211@gmail.com`
- Please include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept material.

We appreciate your responsible disclosure and will work to address the vulnerability promptly.
